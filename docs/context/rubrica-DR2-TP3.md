# Rubrica · DR2-TP3

**3. Gerenciar aplicativos, pacotes, containers e sistemas de inicialização no Linux, utilizando a linha de comando:**

- O aluno demonstrou que sabe diferenciar comandos internos, scripts e binários executáveis
- O aluno demonstrou que sabe inspecionar o processo de inicialização do Linux
- O aluno demonstrou que sabe gerenciar serviços utilizando systemd
- O aluno demonstrou que sabe utilizar corretamente ferramentas de gestão de pacotes
- O aluno demonstrou que sabe relacionar namespaces e cgroups ao funcionamento de containers
- O aluno demonstrou que sabe criar e executar containers Docker
- O aluno demonstrou que sabe utilizar o editor vi para manipular arquivos
- O aluno demonstrou que sabe justificar decisões técnicas com base em evidências coletadas
- O aluno demonstrou que sabe organizar e documentar corretamente os artefatos produzidos
